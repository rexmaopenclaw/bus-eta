# 2026-07-31

## CTB API 發現
城巴/新巴嘅即時 ETA 係用 **rt.data.gov.hk** 唔係 data.etabus.gov.hk！
- Base: `https://rt.data.gov.hk/v1/transport/citybus-nwfb/`
- Route list: `/route/ctb` (return 406 routes)
- ETA: `/eta/ctb/{route}/{bound}` (bound: 1=O, 2=I, 或 O/I)
- Stop: `/stop/{stopId}` 
- Company: `/company/ctb`
- Static data: winstonma.github.io/MMM-HK-Transport-ETA-Data/ctb/

Note: CTB 同 KMB 嘅 ETA 雖然 API 格式唔同，但共用同一個 `KMBETA` type (field 名一樣)
